# 02-requirements

See the [Stage Overview](../Product-Development-Handbook.md#stage-overview) for this stage's purpose, inputs, activities, and outputs.

**Design Patterns:** Methods for requirements elicitation, extraction, and formalization; specification and registry templates; standards for structure, completeness, clarity, and verifiability.

**Completion Criteria:** Requirements are unambiguous, verifiable, and have defined statuses and provenance.
