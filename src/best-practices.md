# Quality Standards and Best Practices

1. [Appendix C: How to Write a Good Requirement — NASA](https://www.nasa.gov/reference/appendix-c-how-to-write-a-good-requirement/)

   Provides checklists for writing and reviewing requirements for clarity, completeness, consistency, traceability, feasibility, and verifiability. Encourages consistent terminology, explicit assumptions, and statements of what is needed rather than how to implement it. Useful for reviewing requirements collected during the interview.

2. [Less Effort, More Completion: The EAS Framework for Simplifying Forms — Nielsen Norman Group](https://www.nngroup.com/articles/eas-framework-simplify-forms/)

   Explains how to reduce user effort: remove unnecessary questions, postpone nonurgent ones, reuse existing information through editable prefilled fields, and simplify remaining inputs. Useful for designing interview rounds and proposed-answer editing.
